# Archived historical data only

The CSVs and summaries in this directory originate from the historical non-bijective P1024-v2. They **do not** measure the new bijective P1024-v3. Rebuild `make full-suite` and rerun on the v3 source to regenerate experimental results. Even new statistical tests do not constitute a cryptographic security proof.

Format v4 changes keyed AEAD initialization but not FrogHash or P1024-v3. AEAD-specific statistical conclusions or ciphertexts from older reports are not v4 test vectors; see V4_TEST_REPORT.md.
